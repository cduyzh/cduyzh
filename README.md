## 🤖 AI × Software Engineering

我正在探索一种新的开发方式：

> **让 AI 不只是生成代码，而是参与需求分析、技术设计、开发、Review、测试与部署整个软件工程流程。**

包括：

```text
Product Requirement
       ↓
AI Requirement Review
       ↓
Technical Design
       ↓
AI / Developer Coding
       ↓
Code Review & Testing
       ↓
CI / Build / Deploy
       ↓
Production
       ↓
Feedback → Next Iteration
```

目标是把 AI 从「代码补全工具」逐渐变成真正的软件工程协作者。
